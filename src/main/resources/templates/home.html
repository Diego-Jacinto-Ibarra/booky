📚 Booky API

Documentación de la API Booky

La forma más sencilla de gestionar y acceder a datos de libros para tus aplicaciones

Introducción

Booky API proporciona acceso a una extensa base de datos de libros, autores y categorías. Utiliza JSON para todas las solicitudes y respuestas.

La URL base para todas las solicitudes es: https://api.booky.com/v1

Fake API

Importante: Esta es una API de demostración (fake API) creada con fines educativos y de pruebas.

Las peticiones GET funcionan completamente y ofrecen múltiples filtros para explorar los datos. Sin embargo, las peticiones POST, PUT y DELETE son simplemente simuladas y no modifican ninguna base de datos real.

Endpoints

GET /books?param=value

Obtiene una lista de libros con opciones de filtrado y paginación.

Parámetros

Nombre Tipo Descripción
title String Filtra por título de libro
author String Filtra por nombre de autor
category String Filtra por categoría
page Integer Número de página (por defecto: 1)
limit Integer Resultados por página (por defecto: 20, máximo: 100)

Ejemplo de respuesta

{ "data": [ { "id": "1", "title": "El nombre del viento", "author": "Patrick Rothfuss", "isbn": "978-8401337208", "category": "Fantasía", "publishDate": "2007-03-27", "description": "Crónica del asesino de reyes: primer día" }, { "id": "2", "title": "1984", "author": "George Orwell", "isbn": "978-0451524935", "category": "Ciencia ficción", "publishDate": "1949-06-08", "description": "Distopía clásica sobre totalitarismo" } ], "meta": { "totalResults": 342, "page": 1, "limit": 20 } }
GET /books/{id}

Obtiene los detalles completos de un libro específico por ID.

Parámetros

Nombre Tipo Descripción
id * String ID único del libro

Ejemplo de respuesta

{ "id": "1", "title": "El nombre del viento", "author": "Patrick Rothfuss", "isbn": "978-8401337208", "category": "Fantasía", "publishDate": "2007-03-27", "description": "Crónica del asesino de reyes: primer día", "pages": 662, "language": "Español", "publisher": "Plaza & Janés", "coverImage": "https://api.booky.com/covers/el-nombre-del-viento.jpg" }
POST /books

Simula la creación de un nuevo libro. Nota: Al ser una API simulada, no se almacenan realmente los datos.

Cuerpo de la solicitud

{ "title": "Título del libro", "author": "Nombre del autor", "isbn": "978-XXXXXXXXXX", "category": "Categoría", "publishDate": "YYYY-MM-DD", "description": "Descripción del libro", "pages": 300, "language": "Español", "publisher": "Editorial" }

Ejemplo de uso

// Ejemplo con JavaScript const fetchBooks = async () => { try { const response = await fetch('https://api.booky.com/v1/books?category=fantasy'); if (!response.ok) { throw new Error(`Error: ${response.status}`); } const data = await response.json(); console.log(data); } catch (error) { console.error('Error fetching books:', error); } };
