📚 Booky API

Documentación de la API Booky

La forma más sencilla de gestionar y acceder a datos de libros para tus aplicaciones

Introducción

Booky API proporciona acceso a una extensa base de datos de libros, autores y categorías. Utiliza JSON para todas las solicitudes y respuestas.

La URL base para todas las solicitudes es: https://api.booky.com/v1

Fake API

Importante: Esta es una API de demostración (fake API) creada con fines educativos y de pruebas.

Las peticiones GET funcionan completamente y ofrecen múltiples filtros para explorar los datos. Sin embargo, las peticiones POST, PUT y DELETE son simplemente simuladas y no modifican ninguna base de datos real.

Endpoints

GET /books

Obtiene una lista de libros con opciones de filtrado y paginación.

Parámetros

Nombre Tipo Descripción
id Integer Filtra por ID de libro
title String Filtra por título de libro
author String Filtra por nombre de autor
category String Filtra por categoría
publisher String Filtra por editorial
publish_date String Filtra por fecha de publicación (formato: Saturday, September 1, 2001)
price Float Filtra por precio
limit Integer Resultados por página (por defecto: ???, máximo: ???)
